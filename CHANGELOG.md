# Changelog

This changelog covers the public NEES Python SDK developer-preview documentation.

## 0.1

Initial developer preview.

Documented:

- `nees-core-sdk` installation
- `NEESClient`
- environment-based API-key configuration
- authenticated chat invocation
- public chat response model
- selected governance result fields
- public SDK exception classes
- security and integration guidance

Current SDK capability:

```text
chat:invoke
```

Future SDK capabilities will be documented only after they become part of the supported public SDK interface.

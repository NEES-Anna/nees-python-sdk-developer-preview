# Security Policy

## Reporting Security Issues

Please do not report suspected security vulnerabilities, exposed credentials,
authentication issues, exploit details, or sensitive traces through public
GitHub issues.

Use the official private contact route published by Nainacore Emotional Tech:

https://nees.cloud

When reporting an issue, include only the minimum information necessary to
reproduce or understand the problem.

Do not include:

- API keys
- passwords
- access tokens
- customer data
- private repository content
- production credentials

## Scope

This repository contains public documentation and examples for the NEES Python SDK.

It does not contain the NEES Core Engine implementation.
